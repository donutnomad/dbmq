# DBMQ 超级演示

这是一个完整的DBMQ使用演示，展示了如何使用DBMQ构建一个订单处理系统。

## 演示场景

**主题**: 创建订单  
**消费组**: 两个消费组同时订阅处理订单消息
- 消费组001: 订单处理服务 (1个分区，1个消费者)
- 消费组002: 数据分析服务 (1个分区，1个消费者)

**运行时长**: 20秒（自动超时关闭）

## 功能特性

✅ **Topic管理**: 自动创建"创建订单"主题，忽略已存在的问题  
✅ **多消费组**: 两个消费组同时订阅同一主题  
✅ **消息生产**: 生产者每2秒发送一条订单消息  
✅ **消息消费**: 消费者实时处理订单消息并打印详细信息  
✅ **优雅关闭**: 20秒后自动关闭所有生产者和消费者  
✅ **中文注释**: 全中文注释，便于理解  
✅ **错误处理**: 完善的错误处理和重试机制  

## 前置要求

### 数据库要求
- MySQL 5.7+ 或 8.0+
- 默认配置:
  - 主机: localhost:3306
  - 用户: root
  - 密码: password
  - 数据库: dbmq_demo (自动创建)

### Redis要求 (可选)
- Redis 6.0+
- 默认配置:
  - 主机: localhost:6379
  - 数据库: 0
- 如果Redis不可用，系统会自动回退到轮询模式

## 配置说明

### 数据库配置
如需修改数据库配置，请编辑 `examples/super_demo.go` 文件中的 `mysqlConfig` 部分：

```go
mysqlConfig := db.MySQLConfig{
    Host:     "localhost",  // 数据库主机
    Port:     3306,         // 数据库端口
    User:     "root",       // 数据库用户
    Password: "password",   // 数据库密码
    DBName:   "dbmq_demo",  // 数据库名称
}
```

### Redis配置
如需修改Redis配置，请编辑 `examples/super_demo.go` 文件中的 `redisConfig` 部分：

```go
redisConfig := db.RedisConfig{
    Host: "localhost",  // Redis主机
    Port: 6379,         // Redis端口
    DB:   0,            // Redis数据库编号
}
```

## 故障排除

### 数据库连接失败
1. 确保MySQL服务正在运行
2. 检查数据库连接参数是否正确
3. 确保数据库用户有创建数据库的权限

### Redis连接失败
1. Redis连接失败不会影响演示运行，系统会自动回退到轮询模式
2. 如需启用Redis优化，请确保Redis服务正在运行

### 权限问题
1. 确保数据库用户有创建数据库、表的权限
2. 确保Go程序有网络访问权限
