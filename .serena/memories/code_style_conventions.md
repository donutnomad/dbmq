# DBMQ 代码风格和约定

## Go 代码风格
- 遵循标准的Go代码风格和gofmt格式化
- 使用驼峰命名法(CamelCase)
- 包名使用小写字母
- 常量使用大写字母和下划线

## 注释规范
- 所有公共函数、结构体、接口都必须有详细的中文注释
- 注释描述功能、参数、返回值和重要的实现细节
- 结构体字段使用中文注释说明用途

## 错误处理
- 使用自定义错误类型，定义在`pkg/errors/`包中
- 错误信息提供足够的上下文信息
- 使用`fmt.Errorf`包装错误以提供调用链信息

## 测试约定
- 测试文件以`_test.go`结尾
- 测试函数以`Test`开头
- 使用testify框架进行断言
- 集成测试以`TestIntegration`开头

## 数据库操作
- 使用GORM进行数据库操作
- 所有数据库操作都在`internal/dal`包中
- 使用事务确保数据一致性
- 结构体标签使用GORM规范

## 并发安全
- 使用互斥锁保护共享状态
- 使用原子操作处理简单的状态标志
- 使用context处理取消和超时
